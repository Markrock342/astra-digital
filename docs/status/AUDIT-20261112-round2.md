## รอบ 3 — ขายได้จริงทั้งวงจร + realtime + ทีมงาน + รายงาน (12 พ.ย.)

- **ลงสินค้าจนขายได้จริง:** ฟอร์มสินค้ามีราคาตัวเลือกแรก · หน้าสินค้ามี "ตัวเลือก ราคา และสต็อก" (ใช้ API งาน 4 ของน็อต #31): เพิ่ม/แก้/ปิด/ลบตัวเลือก · เติมสต็อก ID+รหัสผ่านต่อตัวเลือก (วางจาก Excel ได้) · ดูสต็อกพร้อมขาย/ขายแล้ว/เสีย (ปิดบังรหัส) · ทำเครื่องหมายเสีย/ลบ
- **Realtime:** Durable Object WebSocket `/api/live` ส่งสัญญาณ (ไม่ส่งข้อมูล) เมื่อมีออเดอร์ จ่ายเงิน สต็อก แชท แจ้งเตือน · หน้าจอดึงข้อมูลใหม่ทันที · ถ้าต่อ WebSocket ไม่ได้ ถาม `GET /api/live` ทุก 3 วินาที · หลังบ้านมีจุด "สด/ซิงก์"
- **ทีมงาน (STAFF):** ตั้งค่า › ทีมงาน เพิ่ม/ปิดบัญชี (รหัสชั่วคราวแสดงครั้งเดียว) · ทีมงานเห็นเฉพาะแชท ออเดอร์ คิวพรีออเดอร์ ลูกค้า (ไม่เห็นเงิน) · ส่งของพรีออเดอร์ได้
- **มอบหมายแชท:** เลือกผู้ดูแลในห้องแชท ผู้ถูกมอบหมายได้แจ้งเตือน · แท็บ "ของฉัน"
- **รายงาน:** เมนู "รายงาน" ยอดขายตามสินค้า/ตัวเลือก รายวัน ผู้ซื้อ ยอดสุทธิหักคืนเงิน CSV · `GET /api/admin/reports/sales`
- **UI หลังบ้าน:** สีแบรนด์ ASIA EXTRA (น้ำเงิน) ปุ่มหลัก เมนู ลิงก์ กราฟ · การ์ดขาวบนพื้นเทาเย็น เงาบาง (อ้างอิง shadcn/ui dashboard, MIT)
- **เทสต์ use case ครบวงจร** `tests/journey.spec.mjs`: ลงสินค้า → เติมสต็อก → ลูกค้าซื้อ จ่าย ได้บัญชี รีวิว → ของหมด → เติมสต็อก หน้าร้านอัปเดตเอง → จ่ายไม่สำเร็จ / ของหมดก่อนจ่าย ไม่ได้ของไม่เสียเงิน → พรีออเดอร์ได้คิว ทีมงานส่ง ลูกค้าเห็นเอง → แชท มอบหมาย ตอบ เห็นสด → รายงานและประวัติ
- แก้: เซิร์ฟเวอร์ Node ไม่ส่ง body ของ PATCH/DELETE
