# Design Decisions — แบบร่างหน้าร้าน FIFACORP

วันที่: 2026-11-11  
สถานะ: แบบร่างใหม่ 2026-11-11 โทนเข้มปุ่มเขียวตามไฟล์ที่ Owner ส่งมา ชื่อร้านเป็น FIFACORP และสินค้าเป็นข้อมูลทดสอบ ยังไม่ลงใน `src/`

เปิดดูได้ที่ `docs/bank/mockup/index.html`

เฟรม Figma ชุด ASTRA เป็นทิศทางที่ทดลองไว้ก่อน รอบนี้หน้าแรกเป็นร้าน FIFACORP ไม่ใช้โลโก้ ASTRA และไม่ใช้แผงพาสเทล เปิดด้วยประโยคสั้นกับใบสั่งซื้อตัวอย่าง

## หน้าตาที่ใช้ตอนนี้

- พื้นเกือบดำ ตัวอักษรขาวอมอุ่น ปุ่มหลักปุ่มเดียวสีเขียวอ่อน `#c6fc58`
- หัวร้านเป็นคำว่า FIFACORP พร้อมจุดเขียว ไม่ใช้โลโก้ ASTRA
- หน้าแรกเปิดด้วยประโยคสั้นและใบสั่งซื้อตัวอย่างที่มีรูปสินค้า รหัสถูกปิดเป็นจุด
- การ์ดสินค้าเป็นรูปจัตุรัส ชื่อ ราคาบาท และปุ่มซื้อ สินค้าหมดกดไม่ได้และรูปหม่นลง สั่งจองมีป้ายของตัวเอง
- ขั้นตอนรับสินค้าเป็นแถบเส้นสามช่อง ไม่ใช่การ์ดซ้ำกัน

## หน้าที่อยู่ในแบบร่างรอบนี้

พร้อมส่ง, สินค้าหมด, สั่งจองที่โชว์เลขคิวในประวัติการซื้อ, แชทลูกค้าเป็นไอคอนมุมขวาล่าง กดแล้วเปิดกล่องคุยและปิดได้จุดเดียว, กล่องข้อความที่ทีมงานส่งถึงลูกค้า, กล่องแชทแอดมิน, ตะกร้าเป็นไอคอน และบนมือถือเข้าสู่ระบบอยู่ในเมนู

## Token ชั่วคราว

| ชื่อ | ค่า | ใช้กับ |
|---|---|---|
| bg | `#0b0b09` | พื้นร้าน |
| card | `#171714` | การ์ดและกล่อง |
| line | `#2e2e28` | เส้น |
| lime | `#c6fc58` | ปุ่มหลักและสถานะพร้อม |
| ink | `#f4f3ee` | ตัวอักษร |

ฟอนต์ในแบบร่างคือ IBM Plex Sans Thai ถ้าเครื่องเปิดแบบออฟไลน์จะตกไป Tahoma

## สิ่งที่แบบนี้ยังไม่ใช่

Blocker B1 ยังทำให้ล็อกอินและซื้อของจริงใช้ไม่ได้ เลขคิวกับรหัสในแบบเป็นตัวอย่าง ไม่ได้ต่อ API
