# งานเทคนิคหลังล็อก SOW — มาร์ค / น็อต

อ้างอิง [SOW-FIFACORP-FINAL-20261110.md](SOW-FIFACORP-FINAL-20261110.md)  
ฐานยังเป็น Cloudflare Workers + Durable Object SQLite ชุดเดียวชื่อ `shop` ไม่ย้าย D1 หรือ Neon

## มาร์ค

1. ส่ง SOW ฉบับนี้ให้ลูกค้า รอคำตอบเฉพาะสองจุดที่ยังเปิดอยู่: พรีออเดอร์ต้องจ่ายก่อนได้คิวหรือไม่ และผู้ให้บริการจ่ายเงินจะใช้เจ้าไหน
2. เปรียบเทียบผู้ตรวจสลิปกับเกตเวย์ โดยดูราคา โควตา API และความเข้ากันกับ Cloudflare Workers ยังไม่เปิดช่องจ่าย
3. หลังน็อตได้แบบฐานข้อมูลแล้ว ค่อยทำหน้าหลังบ้านสำหรับนำเข้า ID กับรหัสผ่าน และปุ่มผู้ดูแลใช้ส่งของพรีออเดอร์
4. ไม่เริ่มทิกเก็ต แบนเนอร์หลายชิ้น ฟอนต์หลายแบบ ล็อกอิน LINE หรือส่วนลดสะสม

## น็อต

1. ปรับแบบข้อมูลสินค้าดิจิทัลจากรหัสเดียว เป็น ID กับรหัสผ่าน สองช่อง เข้ารหัสทั้งคู่ และไม่ส่งออกใน API สินค้า
2. ออกแบบสถานะพรีออเดอร์ให้มีเลขคิว และให้ผู้ดูแลเป็นคนส่งของทีหลัง ยังไม่ล็อกว่ารับคิวก่อนหรือหลังจ่าย
3. ตรวจรายงานอันดับผู้ซื้อให้กรองวัน สัปดาห์ เดือน และทั้งหมดได้ โดยยังเปิดเฉพาะผู้ดูแล
4. แบบตารางทิกเก็ตเขียนแยกไว้เป็นทางเลือกงานเพิ่ม ยังไม่ใส่ในฐานที่ใช้งวดนี้

## แบงค์

หน้าร้านให้เหลือโครงเดียว แสดงสินค้าหมด และไม่โชว์รหัสสินค้า งานพรีออเดอร์กับแชทเริ่มหลังแบบข้อมูลของน็อตนิ่ง

## ยังไม่ทำจนกว่าจะมีคำตอบ

- เปิดคิวพรีออเดอร์ก่อนจ่าย หรือหลังจ่าย
- เลือก SlipOK หรือผู้ให้บริการอื่น
- รับทิกเก็ต แบนเนอร์โปรโมชัน และฟอนต์หลายแบบเข้าในราคาเดิม
