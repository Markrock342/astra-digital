# SOW Final — ร้านสินค้าดิจิทัล FIFACORP

อ้างอิงใบเสนอราคา LCS-QT-DGC-2026-001-R06 มูลค่า 100,000 บาท  
วันที่ล็อกขอบเขต: 10 พ.ย. 2026  
งวดที่ 2 จำนวน 40,000 บาท เริ่มเมื่อเดโมฟังก์ชันในเอกสารนี้ทดสอบได้

เอกสารนี้ใช้เฉพาะเรื่องที่ยืนยันแล้วและอยู่ในราคาเดิม สิ่งที่ยังไม่ยืนยันไม่ถือเป็นข้อผูกมัด

## ฟังก์ชันในราคาเดิม

| หัวข้อในใบเสนอราคา | สิ่งที่ล็อกแล้ว |
|---|---|
| หน้าร้านและสมาชิก | สมัครและเข้าสู่ระบบด้วยอีเมลกับรหัสผ่าน |
| แชทในเว็บ | ลูกค้าทักผู้ดูแลในเว็บได้ |
| ตะกร้า คำสั่งซื้อ พรีออเดอร์ | สินค้าพร้อมส่งกับสินค้าพรีออเดอร์ คนละวิธีรับของ |
| สต็อกและส่งมอบสินค้าดิจิทัล | สินค้าหนึ่งรายการส่งเป็น ID และรหัสผ่าน เก็บแบบเข้ารหัส |
| หลังบ้านและรายงานอันดับผู้ซื้อ | อันดับตามยอดซื้อ แยกวัน สัปดาห์ เดือน และทั้งหมด สำหรับผู้ดูแล |
| แจ้งเตือนในเว็บ | ข้อความขึ้นในเว็บไซต์ |
| ช่องทางจ่ายหนึ่งวิธี | ยังไม่เลือกผู้ให้บริการ จ่ายแล้วยอดพร้อมส่งต้องได้รับ ID กับรหัสผ่านทันที |
| ทดสอบ ติดตั้ง ส่งมอบ | เดโมฟังก์ชันชุดนี้ |

## วิธียิงของที่ล็อกแล้ว

- สินค้าพร้อมส่ง: เมื่อยอดได้รับการยืนยัน ระบบส่ง ID และรหัสผ่านให้ทันที
- สินค้าหมด: หน้าร้านแสดงว่าหมด
- พรีออเดอร์: มีเลขคิว ผู้ดูแลเป็นคนส่งของภายหลัง
- ข้อความประกาศบนหน้าร้าน: ใช้ช่องประกาศที่มีอยู่แล้วในตั้งค่าร้านหนึ่งข้อความ
- รหัสผ่านของสินค้าห้ามโผล่ในหน้ารายการสินค้า และห้ามเก็บแบบอ่านออกได้

ลูกค้าต้องยืนยันว่ามีสิทธิ์จำหน่ายและส่งมอบบัญชีประเภท ID กับรหัสผ่านก่อนเปิดขายจริง

## ยังไม่ใช่ข้อผูกมัดในราคานี้

| เรื่อง | สถานะ |
|---|---|
| ล็อกอินผ่าน LINE | ยังไม่ยืนยัน ใช้แค่อีเมลกับรหัสผ่าน |
| ส่วนลดตามยอดสะสมหรือระดับสมาชิก | ยังไม่ยืนยัน มีแค่อันดับผู้ซื้อ |
| แบ่งสิทธิ์พนักงานหลายระดับ | ยังไม่ยืนยัน |
| ปุ่มหรือช่องแชท LINE OA และ Facebook | ยังไม่ยืนยันว่าต้องการทั้งคู่ และยังไม่ยืนยันว่าเป็นลิงก์หรือหน้าต่างฝังในเว็บ |
| ผู้ให้บริการตรวจสลิปหรือเกตเวย์ | ยังไม่เลือก |
| พรีออเดอร์ต้องจ่ายก่อนได้เลขคิวหรือไม่ | ยังไม่ยืนยัน กระทบฐานข้อมูลและขั้นตอนจ่ายเงิน |
| ระบบทิกเก็ตเคลมสินค้า | ลูกค้าต้องการ แต่ไม่อยู่ในใบเสนอราคา ต้องตกลงเป็นงานเพิ่มก่อนลงมือ |
| ระบบแบนเนอร์โปรโมชันหลายชิ้น | เกินช่องประกาศหนึ่งข้อความที่มีอยู่ ต้องตกลงเป็นงานเพิ่มก่อนลงมือ |
| เปลี่ยนฟอนต์ได้หลายแบบ | ลูกค้าต้องการ แต่ไม่อยู่ในใบเสนอราคา ต้องตกลงเป็นงานเพิ่มก่อนลงมือ |

ถ้าจะทำสามรายการท้าย ต้องสรุประดับงานและราคาเพิ่มก่อนเริ่ม
