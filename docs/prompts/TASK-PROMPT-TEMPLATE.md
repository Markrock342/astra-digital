# Task Spec Template (แชทเดียว)

คัดลอกบล็อกด้านล่างไปใช้ในแชท Agent / เก็บใน `docs/prompts/` เมื่อสำคัญ

````markdown
[TASK]
ระบบ: [ชื่อระบบ]
แผนงาน: Phase [X] → Milestone [X.X]
Current Task: [Task ID] - [ชื่องาน]

**รายละเอียดเทคนิค:**
- **เป้าหมาย:** [...]
- **ศัพท์ที่ถูกต้อง:** [...]
- **Flow:** [...]
- **ไฟล์/โมดูลที่เกี่ยวข้อง:** [...]
- **Input / Output:** [...]
- **Security:** [...]
- **Constraints / Error Handling:** [...]
- **Config:** [...]
- **ข้อห้าม:** ห้ามทำนอก Task นี้
- **เกณฑ์ผ่าน:** [...]
- **หลักฐานที่ต้องมี:** [...] รวมรายการไฟล์ที่เปลี่ยน
- **ชั้นเทสที่บังคับ:** [...]
- **Git:** commit หลังผ่านเกณฑ์; ห้าม push จนกว่า Owner สั่ง; push ได้เฉพาะโค้ด — ห้าม push docs/schema
````
