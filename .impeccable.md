## Design Context

### Users
Thai customers browsing and purchasing digital products, with a separate inventory interface for shop staff. This is an interactive presales sandbox.

### Brand Personality
Restrained, familiar, reliable. ASTRA DIGITAL is the independent name from the supplied brief.

### Aesthetic Direction
The user's latest request takes precedence over the attachment: closely match the supplied Nexus screenshots with only small changes. Near-black background, low-contrast grid behind the hero, white bold headline, thin neutral borders, green service indicator, generous spacing, four-column desktop navigation. ASTRA branding; user-approved reference product imagery.

### Design Principles
- Preserve the reference composition and proportions.
- Thai first, with clear shopping and delivery states.
- Test payment labels only where relevant to a purchase or balance.
- Real local server persistence; never expose unsold keys to customers.
- Mobile layouts keep the same visual language without horizontal overflow.
